Calendar check

This page tries every way the website can read your Google Calendar and tells you which ones work. Open it on e25.at for the real answer — opened from your own disk, test 1 cannot pass.

testing

1 · ics.php on your own server

The reliable route. Needs ics.php uploaded next to index.html, and PHP switched on at your host.

testing

2 · Google’s .ics feed, read directly

Free and needs no setup, but Google usually refuses to let a web page read it. Failing here is normal.

waiting

3 · Google Calendar API

Paste an API key to test it. Only needed if 1 and 2 both fail.

testing

4 · Is the calendar public at all?

If every test above fails, this is usually why. Open the calendar file in a new tab — if you see lines of text starting BEGIN:VCALENDAR, it is public. If you get an error page, it is not, and nothing can read it until you fix that.
